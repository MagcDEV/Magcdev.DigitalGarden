# LeetCode repeat tracker: the NeetCode 150

This page has one row for each problem of [[wiki/neetcode-150/index|NeetCode 150 in Go]]. Use it with the [[wiki/neetcode-150/study-method|LeetCode study method]]: you solve each problem four times, on day 0, day 1, day 3 and day 7.

## How to fill a row

Edit this file in Obsidian, or in a text editor. The site only shows it.

1. After the first solve, write the date in **First**, for example `11-12`.
2. After each repeat, write the date in **+1**, **+3** or **+7**.
3. If a repeat is not clean, write `x` and the date. Then do the first solve again, and start the three repeats from that day.
4. A date in **+7** with no `x` means that the problem is learned.

A repeat is clean when you solve the problem with no look at the solution, and the tests pass.

Each morning, look for the rows where the next repeat is due. Solve those problems before you start a new one.

## Totals

Update these three numbers one time each week.

- Problems started: 0 of 150
- Problems learned (clean on day 7): 0 of 150
- Stages complete: 0 of 18
